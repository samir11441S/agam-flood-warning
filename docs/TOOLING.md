## MCP usage

**Agam is an MCP server.** `mcp/server.mts` (stdio; run with `npm run mcp`) exposes three tools to any MCP client (Claude Desktop, Claude Code, others):

| Tool | What it does |
|---|---|
| `list_areas` | Monitored upazilas, rivers, upstream stations and travel times |
| `get_flood_risk` | Current (or replayed) alert level per area, with the evidence and arrival time |
| `draft_alert` | Verified Bangla alert template and its safety-check results for an area |

Why: disaster officials and NGOs increasingly use AI assistants. With MCP, an assistant can answer "Which unions in Feni need to evacuate tonight, and what should we tell them?" from Agam's verified engine instead of guessing.

Add it to Claude Desktop (`claude_desktop_config.json`), replacing the path with yours:

```json
{
  "mcpServers": {
    "agam": { "command": "npx", "args": ["tsx", "C:/path/to/agam/mcp/server.mts"] }
  }
}
```

## Integrations (all optional; Agam runs in test mode without them)

| Integration | Where | Purpose |
|---|---|---|
| Any Bangladeshi bulk-SMS gateway with an HTTP API, or Twilio | `src/lib/channels.ts` | SMS to households, volunteers and officers |
| Any IVR / voice-call provider with an HTTP API | `src/lib/channels.ts` | Bangla voice calls |
| Incoming-SMS webhook `/api/sms/inbound` | protected by `INBOUND_SECRET` | Officer approvals by SMS, residents' `PANI` reports |
| Call-status webhook `/api/voice/status` | protected by `INBOUND_SECRET` | Retries for unanswered calls |
| Telegram Bot API (long polling) | `src/lib/bot.ts`, run by the worker | Subscriptions, replies, reports, officer approval buttons |

**MCP used during the build:** the Claude Code desktop app's built-in browser-preview MCP tools were used to run and click through the UI for testing. No other MCP servers were used.
