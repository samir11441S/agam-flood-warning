# Geospatial ML flood-onset model — evaluation

Generated by `npm run train:ml` (scripts/train-ml.mts). Model: L2-regularised logistic regression on 9 features computed from each area's **upstream network** — rain at every linked upstream station relative to that station's own 2-year level, how many upstream stations are raining hard at once, 7-day saturation, local rain, river flow and season. It estimates the chance that a damaging flood **starts within 72 hours**.

**Validation is out of sample:** 5 folds of 6 whole years; every number below comes from years the model never saw.

| | Result |
|---|---|
| Area-days scored | 262,800 (140 labelled "flood starts within 72 h") |
| Held-out ROC AUC | **0.912** (1.0 = perfect ranking, 0.5 = chance) |
| ML Watch on or before onset | **28 of 35** documented area-floods (median lead 3 days) |
| Rule engine Watch (or higher) on or before onset | 26 of 35 |
| Rule engine Danger on or before onset | 20 of 35 |

## How it is used, and limits

- In the app the model is **extra evidence**: when an area scores in the top 1.9 % of all days since 1994, it can raise the area to **Watch** (look closely, get ready). It never raises Warning or Danger — the rule engine and an officer decide those.
- Labels come from only 9 documented flood events (35 area-floods). Floods that were never documented count as "no flood", so true skill is probably better than the numbers above suggest, and the model must be retrained as the pilot records more events.
- Inputs are ERA5 (~25 km) and GloFAS; very local storms are under-represented, exactly as for the rule engine (see EVALUATION.md).
