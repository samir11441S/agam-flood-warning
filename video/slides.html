Every channel

Not everyone has a smartphone.

  • 📞 Voice call + SMS to any phone, through any Bangladeshi gateway
  • Answer from any phone: reply 1 = safe, 2 = need help — or press 1 / 2 on the call
  • Residents text PANI <area> to report rising water
  • Telegram for smartphones: ✅ আমি নিরাপদ or 🆘 সাহায্য দরকার → a pin on the rescue map
  • 🌙 At night: no answer from officer 1 → Agam texts officer 2, then 3

AI approach

Input → rules → AI → human → every household

1 · Input

Live data, every hour

Rain at 15 upstream points · river flow (GloFAS) · tide · residents' "PANI" SMS reports

2 · Risk engine (no AI)

Rules decide the level

Thresholds from 30 years of local data (ERA5) → Normal / Watch / Warning / Danger + arrival time, with the reason

3 · Claude (LLM)

Writes the words

Grounded only in verified facts (no RAG needed) · personalised: area, Bangla / dialect, local committee as sender

4 · Guardrails + human

Checked, then approved

7 automatic checks → verified template if any fails · officer approves (2 for Danger) · escalates at night

5 · Output

Reach + feedback

Voice + SMS, most vulnerable first · volunteers · replies 1 / 2 · MCP server for other AI agents

Built with: Claude API (claude-opus-5-5) · Next.js · Leaflet / OpenStreetMap · Copernicus ERA5 & GloFAS via Open-Meteo · Model Context Protocol
